# LifeDesk AI – Personal Document Assistant Using Hybrid RAG

LifeDesk AI is an AI-powered document assistant that helps users upload documents and ask questions to retrieve relevant information using Retrieval-Augmented Generation (RAG).

### Features
- Supports PDF, DOCX, and TXT files.
- Document processing and text chunking.
- BM25 keyword-based search.
- Semantic search for relevant information.
- Hybrid retrieval for improved search results.
- OpenAI GPT-4o-mini integration.
- Source references with document names and page numbers.
- Evidence-based question answering.

### Tech Stack
Python | LangChain | RAG | BM25 | Semantic Search | OpenAI API | GPT-4o-mini | Streamlit

### Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
